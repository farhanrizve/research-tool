## 2. Proposal Structure

### 2.1 Project Title

**Format:** Clear, descriptive, specific

```
[TYPE] + [DOMAIN/AREA] + [METHOD/APPROACH]

Examples:
- "Explainable Machine Learning Framework for Type 2 Diabetes Prediction"
- "Crowdsourced Missing Person Search Platform with Real-time AI Image Recognition"
- "Adaptive Assessment System Using Computerized Adaptive Testing and Dynamic Bayesian Networks"
```

### 2.2 Introduction

**Length:** 4-6 paragraphs (continuous text, no sub-headings)

**Content Structure:**

1. **Problem Context (1-2 paragraphs)**
   - Global/statistical background
   - Current state of the problem
   - Significance of the issue

2. **Current Solutions & Limitations (1-2 paragraphs)**
   - Existing approaches
   - Gaps and inadequacies
   - Need for improvement

3. **Proposed Solution (1-2 paragraphs)**
   - Overview of your solution
   - Key features/capabilities
   - Expected impact

### 2.3 Proposal Keywords

**Format:** Comma-separated, alphabetically ordered

**Example:**
```
Type 2 Diabetes (T2D), Machine Learning (ML), Explainable AI (XAI), 
Clinical Biomarkers, Risk Prediction, Risk Stratification, Feature Importance, 
Random Forest, XG-Boost, Support Vector Machine (SVM)
```

**Guidelines:**
- 8-12 keywords
- Include domain-specific terms
- Add technical/methodological terms

## 3. Background and Motivation

### 3.1 Content Structure

**Length:** 2-3 paragraphs

**Content:**
- Detailed context of the problem
- Why it matters (global/local significance)
- Current research landscape
- End with project aim statement

### 3.2 Writing Guidelines

- Use active voice where possible
- Include recent statistics (last 3-5 years)
- Cite authoritative sources
- End with project aim statement

**Example ending:**
```
This project aims to bridge this gap by developing an [SOLUTION] that not only 
[PREDICTS/ANALYZES/DETECTS] [TARGET] accurately but also [ADDITIONAL VALUE] 
for [USERS/BENEFICIARIES].
```

---

## 4. Justification

### 4.1 Structure

**Numbered sections (1., 2., 3., etc.)**

Each point:
- **Heading:** Bold, numbered statement
- **Explanation:** Multiple sentences supporting the point

**Sample Format (from actual proposal):**
```
1. Rising Disease Burden
   The global prevalence of T2D is increasing at an alarming rate due to changing 
   lifestyles, dietary habits, and sedentary behavior. Without early identification 
   and preventive care, patients are at higher risk of developing chronic complications, 
   which place a substantial burden on both individuals and healthcare systems.

2. Cost and Time Efficiency
   Traditional diagnostic methods for T2D, such as repeated blood tests and physician 
   evaluations, are often costly, labor-intensive, and time-consuming. These limitations 
   make large-scale screening challenging, particularly in low-resource settings...
```

### 4.2 Content Guidelines

- Include 4-6 justified points
- Each point should be distinct
- Build a logical argument
- End with summary statement

### 4.3 Sample Content Areas

Based on proposal sample, include:

1. **Rising Problem Burden** - Statistics, growth trends
2. **Cost/Time Efficiency** - Comparison with traditional methods
3. **Technical Feasibility** - ML/AI capabilities, accuracy
4. **Interpretability/Trust** - Explainability benefits
5. **Practical Applicability** - Real-world deployment potential

## 5. Scope

### 5.1 Structure

**Numbered sections (1., 2., etc.) with sub-bullets**

```
1. Data Sources:
   o [Bullet point 1]
   o [Bullet point 2]

2. Machine Learning Models:
   o [Bullet point 1]
   ▪ [Sub-bullet for algorithm]
   ▪ [Sub-bullet for algorithm]
```

**Key bullets:** Use "o" for main bullets, "▪" for sub-bullets

### 5.2 Content Sections

Based on proposal sample:

```
1. Data Sources:
   o [Data types used]

2. Machine Learning Models:
   o [Algorithms]

3. Applications:
   o [Use cases]

4. Limitations:
   o [What is NOT included]

5. Future Scope:
   o [Potential extensions]
```

### 5.3 Content Guidelines

- **Be specific** about data, models, applications
- **Limitations:** Clearly state boundaries
- **Future Scope:** Show awareness of extensions

## 6. Research Plan and Methodology

### 6.1 Structure

**Numbered sections (1., 2., 3., etc.)**

**Key bullets:** Use "●" for main bullets, "o" for sub-bullets

```
1. Data Collection and Preprocessing
   ● Dataset: [Description]
   ● Data Cleaning: [Activities]
   ● Normalization: [Activities]
   ...

2. Model Development
   ● Machine Learning Models:
     o [Algorithm 1]
     o [Algorithm 2]
```

### 6.2 Content Structure (Typical)

```
1. Data Collection and Preprocessing
   ● Dataset: [Dataset description]
   ● Data Cleaning: [Missing values, outliers]
   ● Normalization: [Scaling techniques]
   ● Feature Selection: [Selection methods]
   ● Data Splitting: [Train/test ratio]

2. Model Development
   ● Machine Learning Models: [List algorithms]
   ● Training Strategy: [Hyperparameter tuning, cross-validation]

3. Model Evaluation
   ● Performance Metrics: [Accuracy, Precision, Recall, F1, ROC-AUC]
   ● Visualization Tools: [Confusion matrix, ROC curve]

4. [Domain-specific phase]
   ● [Activities]

5. Deployment and Testing
   ● [Activities]

6. Expected Outcomes
   ● [Deliverables]
```

### 6.3 Guidelines

- Use standard SDLC phases
- Be specific about methods
- Include evaluation metrics
- Show clear phases and outputs

## 7. Expected Outcomes

### 7.1 Structure

**Numbered sections with bullet points**

```
1. [Outcome 1]
   ● [Brief explanation]

2. [Outcome 2]
   ● [Brief explanation]
```

### 7.2 Content Guidelines

- 3-5 concrete outcomes
- Be measurable/verifiable
- Link to objectives

**Sample (from actual proposal):**
```
1. Accurate Prediction
   ● Fast and reliable prediction of Type 2 Diabetes risk.

2. Transparency
   ● Clear understanding of key factors influencing predictions through 
     feature importance analysis.

3. Clinical Usability
   ● User-friendly reports and visualizations to assist clinicians in 
     decision-making.
```

## 8. References

### 8.1 Format

**Numbered inline citations [1], [2], [3]**

**Citation Style (from sample):**
```
[1] Author(s). "Title". [Publication details].

[2] Author(s). "Title". Journal/Conference.
```

Note: No formal punctuation like periods after year - just author and title.

### 8.2 Guidelines

- Minimum 10-15 references
- Include recent publications (last 5 years)
- Use academic sources (journals, conferences)
- Mix of theoretical and applied

**Sample References (from actual proposal):**
```
[1] Shahid Mohammad Ganie, Majid Bashir Malik. "An ensemble Machine 
    Learning approach for predicting Type-II diabetes mellitus based on 
    lifestyle indicators".

[2] Shatabdi Das, Riaz Rahman, Ashis Talukder. "Determinants of 
    developing cardiovascular disease risk with emphasis on type-2 
    diabetes and predictive modeling utilizing machine learning algorithms".

[3] Md Rakibul Haque, Ibraheem Alharbi. "A Dataset-Specific Machine 
    Learning Study for Predicting Diabetes (Type-2) in a Developing 
    Country Context".
```

## 9. Formatting Standards (WUB CSE)

### 9.1 Page Margins

| Side | Measurement |
|------|-------------|
| Top | 1 inch |
| Bottom | 1 inch |
| Left | 1.2 inches |
| Right | 0.80 inches |

### 9.2 Font Specifications

| Element | Font | Size | Style |
|---------|------|------|-------|
| Title | Cambria | 14pt | Bold |
| Heading 1 | Times New Roman | 12pt | Bold |
| Heading 2 | Times New Roman | 12pt | Bold |
| Body | Times New Roman | 12pt | Justified |
| Line Spacing | 1.5 | | |

### 9.3 Figure/Table Formatting

- **Figure captions:** Below image, centered, "Figure X.X: Title"
- **Table captions:** Above table, centered, "Table X.X: Title"
- **Reference in text:** "as shown in Figure 1.1" or "Table 2.1 presents"

## 11. Quality Checklist

Before submission, verify:

- [ ] Title approval form complete with all signatures
- [ ] Introduction 4-6 paragraphs with clear problem statement
- [ ] 8-12 proposal keywords listed
- [ ] Background includes recent statistics
- [ ] Justification has 4-6 distinct points
- [ ] Scope clearly defined with numbered sections (1., 2., etc.)
- [ ] Research plan has clear phases with proper bullet markers
- [ ] 3-5 expected outcomes stated
- [ ] 10-15 references in correct format
- [ ] Margins: 1"/1"/1.2"/0.80"
- [ ] Font: Times New Roman 12pt body
- [ ] Line spacing: 1.5
- [ ] Justified alignment
- [ ] No spelling/grammar errors

## 13. Common Mistakes to Avoid

1. **Vague title** - Be specific about method and domain
2. **Weak justification** - Use evidence, not just opinions
3. **Undefined scope** - Clearly state in and out of scope
4. **Generic methodology** - Customize to your project
5. **Missing limitations** - Always acknowledge boundaries
6. **Poor references** - Include recent, relevant sources
7. **Formatting errors** - Follow WUB CSE standards
8. **Wrong bullet markers** - Use "o" for Scope, "●" for Methodology
