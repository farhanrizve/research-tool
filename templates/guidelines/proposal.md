# Proposal Guidelines

## Overview

Guidelines for writing and preparing the research proposal.

### Keywords (include in proposal)

Essential keywords that should appear in your proposal:

| Keyword | Notes |
|---------|-------|
| Text Mining | Use in title, abstract, and throughout |
| Job Posting Analysis | Core methodology focus |
| Skill Extraction | Primary research objective |
| NLP | Natural Language Processing |
| CSIT | Computer Science and Information Technology |
| Bangladesh | Geographic scope |

### Title Suggestions

Based on supervisor guidance:

> **"Skill Demand Analysis in the CSIT Job Market of Bangladesh: A Cross-Country Comparative Study Using Text Mining and Hybrid NLP"**

Alternative variants:
- "Analyzing Skill Demand Trends in Bangladesh's CSIT Job Market Using Text Mining of Job Postings"
- "Skill Demand Trends in Bangladesh's CSIT Job Market: A Comparative Study with Developed Nations"

### Where to Include Keywords

- **Title**: Include primary keywords (Text Mining, CSIT, Bangladesh)
- **Abstract**: 2-3 keywords at the end
- **Introduction**: Use naturally in first paragraph
- **Methodology**: Describe text mining approach

### Research Scope Clarification

- **DO NOT** mention specific university or institution names
- Focus on **Bangladeshi CSIT graduates** as a population (not specific institutions)
- The study examines skill gaps at **national AND international levels**
- NLP model analyzes **job posting data only** (not curriculum analysis)

### Research Justification - Cross-Country Comparison

The proposal should justify the cross-country comparative analysis with developed nations (USA, Canada, Australia).

#### Primary Novelty

**Cross-Country Comparison of Skill Requirements for Similar Jobs at Same Seniority Levels**

This research is the first comprehensive analysis that compares skill requirements in Bangladesh CSIT job market with developed nations (USA, Canada, Australia) for similar job roles at matched seniority levels.

#### Why Compare with Developed Nations?

| Reason | Description |
|--------|-------------|
| Research Gap | No existing study compares Bangladesh CSIT skill demands with developed nations |
| Global Benchmarking | See how Bangladesh compares with mature job markets |
| Curriculum Relevance | Help universities align with international standards |
| Graduate Value | Show graduates what skills matter for international opportunities |

#### How to State in Proposal

```markdown
## Research Justification

This research addresses a critical gap in Bangladesh CSIT labor market
studies by conducting the first comprehensive cross-country comparison
of skill requirements. While skill demands in developed nations like
the USA, Canada, and Australia have been extensively studied, no
prior research has compared these requirements with Bangladesh at the
same seniority levels. This comparison will reveal:

1. Skills that Bangladesh jobs require but developed nations don't
2. Skills that developed nations require but Bangladesh doesn't
3. Common skills across all three countries for similar job roles

This knowledge will help universities update curricula and prepare
graduates for both local and international job markets.
```

## In-Text Citations

Harvard referencing style uses the **author-date system**.

### Citation Types

| Type | Format | Example |
|------|--------|---------|
| **Parenthetical** | `(Author, Year)` | `(Smith, 2023)` |
| **Narrative** | `Author (Year)` | `Smith (2023) argues...` |

### When to Cite

- **Every time you use someone's idea, data, or argument** - cite it
- **Direct quotes** - add page number: `(Smith, 2023, p. 48)`
- **Multiple pages**: `(Smith, 2023, pp. 48-52)`

### Author Variations

| Authors | Format |
|---------|--------|
| 1 author | `(Smith, 2023)` |
| 2 authors | `(Smith and Jones, 2023)` |
| 3+ authors | `(Smith et al., 2023)` |
| No date | `(Smith, n.d.)` |
| Same author, same year | `(Smith, 2025a)`, `(Smith, 2025b)` |

### Reference List

- Alphabetical by author surname (not numbered)
- Format: `Author (Year). Title. Publisher.`

### Reference Examples

**Book**:
```
Smith, J. (2023). Machine learning: A practical approach. Academic Press.
```

**Journal Article**:
```
Jones, A. and Khan, R. (2022). "Deep learning methods for NLP", Journal of Artificial Intelligence, 15(3), pp. 45-67.
```

**Conference Paper**:
```
Rahman, M. (2021). "Skill extraction from job postings", Proceedings of ICCSE 2021, Dhaka, pp. 112-118.
```

**Website**:
```

```

**Thesis**:
```

```
